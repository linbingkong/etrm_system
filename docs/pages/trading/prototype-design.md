# 交易管理模块原型设计

## 1. 设计目标

交易管理模块面向交易决策人员，核心目标是快速完成“看交易状态、识别申报风险、编辑量价曲线、提交交易申报”。页面应延续市场监测的深色控制台风格，同时更强调可编辑表格、曲线校验和关键操作状态。

## 2. 模块信息架构

交易管理
├── 交易总览
│   ├── 交易状态栏

│   ├── 量价申报表
│   ├── 校验结果

├── D1 曲线申报

## 3. 交易总览原型

### 3.1 桌面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 状态栏：交易日 | 市场类型 | 当前轮次 | 申报窗口 | 更新时间        │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┤
│ 待申报   │ 已提交   │ 成交电量 │ 申报均价 │ 偏差风险 │ 待办数量 │
├──────────────────────────────────────────────┬───────────────┤
│ 交易流程进度：市场监测 → 现货申报 → D1 曲线 → 结算联动       │ 风险提醒 │
├──────────────────────────────┬───────────────┬───────────────┤
│ 交易待办                     │ 交易结果摘要   │ 快捷入口       │
└──────────────────────────────┴───────────────┴───────────────┘
```

### 3.2 重点展示

- 交易窗口状态：开市中、即将关闭、已闭市。
- 当前轮次：日前申报、实时调整、D1 曲线。
- 风险提醒：价格越限、缺失时段、爬坡约束、偏差过大。
- 待办入口：现货交易申报、D1 曲线申报、交易约束复核。

## 4. 现货交易申报原型

### 4.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 筛选栏：交易日 | 市场类型 | 申报轮次 | 交易单元 | 24点/96点      │
├──────────────────────────────────────────────┬───────────────┤
│ 申报曲线图：申报电量 / 参考价格 / 最高限价 / 最低限价          │ 校验结果 │
├──────────────────────────────────────────────────────────────┤
│ 量价申报表：时段、预测负荷、申报电量、申报价格、参考价、状态、备注 │
├──────────────────────────────────────────────────────────────┤
│ 操作栏：暂存 | 校验 | 提交 | 撤回 | 导出                         │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 表格字段

| 字段 | 说明 |
|---|---|
| 时段 | 24 点或 96 点时段 |
| 预测负荷 | 来自市场监测或预测模型 |
| 申报电量 | 用户填报，单位 MWh |
| 申报价格 | 用户填报，单位 元/MWh |
| 参考价格 | 日前/实时/策略参考价 |
| 状态 | 正常、预警、越限、缺失 |
| 备注 | 校验说明或人工备注 |

### 4.3 操作状态

- 暂存：保存草稿，不提交交易中心。
- 校验：检查价格上下限、缺失点、总电量偏差。
- 提交：仅在校验通过且窗口开启时可用。
- 撤回：仅已提交且仍在窗口期内可用。
- 导出：按权限控制。

## 5. D1 曲线申报原型

### 5.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 筛选栏：交易日 | 曲线类型 | 机组/交易单元 | 24点/96点          │
├──────────────────────────────────────────────┬───────────────┤
│ 曲线图：计划曲线 / 申报曲线 / 预测负荷 / 偏差区间              │ 约束校验 │
├──────────────────────────────────────────────────────────────┤
│ 曲线明细：时段、计划电量、申报电量、预测负荷、偏差、状态、备注   │
├──────────────────────────────────────────────────────────────┤
│ 操作栏：保存草稿 | 校验 | 提交                                  │
└──────────────────────────────────────────────────────────────┘
```

### 5.2 校验规则

- 曲线点数完整：24 点或 96 点必须全部有值。
- 出力上下限：申报电量不能超过机组或交易单元约束。
- 爬坡约束：相邻时段变化不能超过阈值。
- 偏差阈值：计划与申报偏差超过阈值时标红。

## 6. 视觉规范

颜色沿用 `docs/pages/pages_design_V1.md`：

- 背景：`#0A1128`
- 面板：`rgba(17, 28, 68, 0.75)`
- 主高亮：`#00F2FE`
- 风险红：`#FF3860`
- 安全绿：`#00E676`
- 预警黄：`#FFB300`
- 次要文字：`#8F9BBA`

布局要求：

- 卡片间距使用 `12px` 或 `16px`。
- 表格保持紧凑行高，适合 96 点申报。
- 操作按钮固定在表格下方或页面底部操作栏。
- 关键数字使用等宽字体，避免量价刷新时抖动。

## 7. 响应式规则

- 桌面端：图表与校验面板采用 `2/3 + 1/3`。
- 中屏：图表与校验面板上下排列。
- 小屏：筛选栏和操作栏换行，表格横向滚动。
- 96 点表格不压缩字段，采用横向滚动保证可读性。

## 8. 状态设计

必须覆盖：

- 正常：展示 mock 交易状态与申报数据。
- 加载中：图表和表格局部 loading。
- 空数据：提示当前交易日暂无申报数据。
- 校验失败：校验面板展示失败原因，表格对应行高亮。
- 已闭市：表格只读，提交和撤回禁用。
- 无权限：提交、撤回、导出按钮隐藏或禁用。
- 提交成功：状态变为已提交，生成操作记录。

## 9. 与其他模块联动

- 从市场监测价格异常进入现货交易申报。
- 从交易总览进入价格监测查看参考价格。
- 交易提交结果后续进入结算总览和结算审核。
- D1 曲线申报与机组约束、发电目标、交易约束联动。
- 交易待办同步回工作台首页。

## 10. 原型验收标准

- 交易总览、现货交易申报、D1 曲线申报具备清晰页面结构。
- P0 页面优先，P1/P2 页面不阻塞 V1 开发。
- 现货申报和 D1 曲线均支持 24/96 点展示。
- 图表、表格、校验和操作区层级清晰。
- 风险、越限、无权限、已闭市状态可识别。
- 原型可直接转化为 Vue 组件拆分和测试用例。
## 11. 现货交易申报重设计补充

### 11.1 页面定位

现货交易申报页调整为“独立储能日前报量报价策略生成”工作台。页面以预测日前电价为输入，交易员填写或复核储能参数后，由后端策略服务生成充电量价曲线、放电量价曲线、功率曲线、SOC 曲线和收益测算结果。

### 11.2 页面结构

```text
现货交易申报 / 独立储能日前策略
├─ 顶部预测出清量价曲线：24点/96点切换，展示预测日前电价和放电价格信号
├─ 策略列表：策略名称、生成状态、更新时间
├─ 三步策略信息：填写参数 → 充放电策略 → 策略收益测算
├─ 储能参数区：功率上限、SOC 上下限、初始/期末 SOC、效率、时长、价格边界、成本参数
├─ 策略曲线区：充放电功率、SOC、预测价格
├─ 充放电策略表：充电/放电分段出力和申报电价
└─ 收益测算：预期收入、充电成本、退化成本、可变费用、风险成本、预期收益
```

### 11.3 联调接口

页面通过 `POST /api/v1/trading/spot-bid/storage-strategy` 调用后端策略服务。请求使用 96 点 `charge_price_signal` 与 `discharge_price_signal`，响应展示 `charge_segments`、`discharge_segments`、`derived_feasible_power_mw`、`derived_soc` 和 `submission_packet.daily_params`。
