# 工作台首页原型设计

## 1. 设计依据

本页面视觉规范以 `docs/pages/pages_design_V1.md` 为准，采用深色控制台风格，强调数据密度、实时状态、风险识别和电力交易科技感。

页面对应路由：`/dashboard`

页面定位：系统登录后的首屏工作台，面向交易员、结算人员、数据分析人员和系统管理员，帮助用户快速完成“看状态、进任务、查风险、进高频功能”。

## 2. 设计原则

- 数据至上：所有视觉元素服务于业务数据可读性和风险识别。
- 深色为主：采用控制室式深色背景，降低长时间盯盘疲劳。
- 高对比预警：偏差、越限、待审、风险等信息必须一眼可见。
- 高信息密度：首屏尽量承载核心指标、趋势、任务和入口。
- 操作直达：高频入口不超过一次点击进入目标页面。

## 3. 视觉规范

颜色：

| 用途 | 色值 | 说明 |
|---|---|---|
| 系统背景 | `#0A1128` | 深邃底色，营造控制台氛围 |
| 卡片背景 | `rgba(17, 28, 68, 0.75)` | 半透明深蓝面板 |
| 主高亮 | `#00F2FE` | 核心指标、选中态、主按钮 |
| 次级高亮 | `#0072FF` | 链接、辅助线、次级状态 |
| 风险红 | `#FF3860` | 价格飙升、严重偏差、越限 |
| 安全绿 | `#00E676` | 安全、稳定、回落、完成 |
| 预警黄 | `#FFB300` | 常规提醒、预测提示、待处理 |
| 次要文字 | `#8F9BBA` | 时间戳、标签、说明 |

字体：

- 中文：`PingFang SC`, `Microsoft YaHei`, sans-serif。
- 数字：`Roboto Mono`, `DIN Alternate`, monospace。
- KPI 数字建议 `28px - 36px`，核心趋势数字可放大到 `40px`。
- 正文和表格为 `14px`，辅助信息为 `12px`。

卡片：

- 圆角控制在 `2px - 4px`。
- 间距使用 `12px` 或 `16px`。
- 边框使用 `1px solid rgba(0, 242, 254, 0.15)`。
- 激活或风险卡片可增加微弱外发光：`0 0 8px rgba(0, 242, 254, 0.3)`。

## 5. 页面布局

### 5.1 桌面端布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 顶部状态栏：用户 / 角色 / 交易日 / 天气 / 市场状态 / 设置        │
├────────────┬────────────┬────────────┬────────────┬────────────┤
│ KPI 1      │ KPI 2      │ KPI 3      │ KPI 4      │ KPI 5      │
├──────────────────────────────────────────────┬───────────────┤
│ 日前 / 实时价格趋势图                         │ 待办任务       │
│ ECharts 折线 + 面积渐变 + 风险标记线           │ 风险提醒       │
├──────────────────────┬───────────────────────┬───────────────┤
│ 快捷导航             │ 动态通知                │ 业务数据卡片   │
└──────────────────────┴───────────────────────┴───────────────┘
```

建议比例：

- 顶部状态栏：高度 `64px - 72px`。
- KPI 区：5 列等宽。
- 核心趋势区：左侧占 `2/3`，右侧占 `1/3`。
- 底部工作区：三列等宽或 `3:3:2`。

### 5.2 中屏布局

- KPI 区改为 3 + 2 换行。
- 趋势图和待办任务上下排列。
- 快捷导航、通知、业务数据按两列排列。

### 5.3 移动端布局

- 全部单列。
- KPI 卡片改为两列或横向滚动。
- 快捷导航使用两列按钮。
- 趋势图高度不低于 `280px`。

## 6. 模块原型说明

### 顶部状态栏

展示内容：

- 用户：例如“王交易员”
- 角色：例如“交易决策人员”
- 交易日：例如“2026-06-12”
- 天气：例如“济南 晴 31℃”
- 市场状态：开市中、已闭市、结算中

交互：

- 市场状态使用高对比标签。
- 点击快捷设置进入后续配置入口。

### KPI 指标区

指标：

- 今日交易电量：MWh
- 月度交易电量：MWh
- 综合均价：元/MWh
- 预估收益：万元
- 偏差率：%

表现：

- 数字使用等宽字体。
- 上涨或高风险使用 `#FF3860`。
- 安全或回落使用 `#00E676`。
- 常规提醒使用 `#FFB300`。

### 核心趋势区

图表：

- ECharts 折线图。
- 日前价格与实时价格两条线。
- 面积渐变填充。
- 预留最高限价、最低限价、风险阈值 MarkLine。

交互：

- Hover 显示时段、日前价格、实时价格、价差。
- 支持后续扩展到 96 点或 288 点曲线。

### 待办与风险区

内容：

- 待交易申报
- 待结算审核
- 待合同处理
- 偏差预警

表现：

- 高优先级使用红色边线。
- 中优先级使用黄色状态。
- 已临近截止的任务置顶。

### 快捷导航区

入口：

- 现货交易申报：`/trading/spot-bid`
- D1 曲线申报：`/trading/d1-curve`
- 结算审核：`/settlement/review`
- 合同列表：`/contracts/list`
- 价格监测：`/market-monitoring/prices`
- 策略列表：`/strategy/list`

表现：

- 使用图标 + 名称 + 简短说明。
- 支持后续按用户自定义排序。

### 动态通知 / 业务数据区

动态通知类型：

- 市场动态
- 系统公告
- 风险提示

业务数据卡片：

- 已申报交易数
- 待审核结算单
- 合同即将到期
- 实时告警数量

## 7. 状态设计

必须覆盖：

- 加载中：卡片骨架屏或局部 loading。
- 空数据：显示明确的空状态文案。
- 异常：展示业务可读错误。
- 无权限：入口置灰或不显示。
- 风险预警：使用红色高对比样式。

首版 mock 页面可用静态数据模拟正常状态；测试中至少覆盖正常渲染。

## 8. 验收标准

- 页面遵循 `docs/pages/pages_design_V1.md` 的深色科技控制台风格。
- `/dashboard` 不再显示占位页。
- 首屏能看到顶部状态栏、KPI、趋势图、待办、快捷导航和通知。
- KPI 数字、价格、偏差率单位清晰。
- 趋势图具备日前和实时两类数据。
- 移动端布局不重叠。
- 前端测试和构建通过。
