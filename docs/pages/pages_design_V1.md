# UI/UX 设计规范

---

## 一、 设计核心原则

* **数据至上（Data-First）：** 拒绝毫无意义的炫酷动效，所有科技感视觉元素（如外发光、网格线）必须为提高数据可读性、突出交易风险服务。
* **深色为主，浅色为辅（Dark-Mode Centric）：** 交易大屏及日前/实时交易决策采用深色模式，降低全天候盯盘交易员的视觉疲劳；合同管理、结算对账等文本密集型模块可支持一键切换高亮（Light）模式。
* **警示分明（High Contrast Alert）：** 交易市场瞬息万变，利用极高饱和度的功能色，确保偏差考核预警和限价触达在暗色背景中“一眼可见”。

---

## 二、 色彩规范（Color Palette）

电力交易科技感色彩通常由**深邃底色、荧光科技色、以及行业功能色**组成。

### 1. 基础背景与主色调

| 色样 | 色值 | 适用场景 | 视觉心理 |
| --- | --- | --- | --- |
| **深邃底色 (Deep Space)** | `#0A1128` | 系统大背景、大屏底色 | 营造深夜控制室的沉浸感与深邃感 |
| **面板底色 (Card BG)** | `#111C44` | 组件卡片、表格行、弹窗背景 | 增强层级感，微弱的幽蓝色调 |
| **科技主色 (Cyan Blue)** | `#00F2FE` | 按钮、选中状态、核心指标高亮 | 荧光青色，代表高效、未来感与电能 |
| **辅助主色 (Neon Blue)** | `#0072FF` | 渐变搭配、常规链接、次级高亮 | 稳重的电力科技蓝 |

### 2. 行业功能色（量价与风控）

> **⚠️ 行业避坑提示：** 在中国电力系统中，红/绿具有双重含义。**财务/金融视角**下红涨绿跌；但**国网一次设备视角**下红灯代表带电/合闸（危险），绿灯代表不带电/分闸（安全）。本系统作为“交易决策”系统，建议遵循**金融及风控标准**：

* **价格上涨/高风险（Alert Red）：** `#FF3860`（荧光红/霓虹粉）—— 用于价格飙升、严重偏差考核预警、风控越限。
* **价格下跌/安全稳定（Safe Green）：** `#00E676`（荧光绿）—— 用于出清价格回落、偏差在安全范围内、绿电交易标识。
* **中性/预测提示（Warning Yellow）：** `#FFB300`（琥珀金）—— 用于日前负荷预测线、常规提醒。

## 三、 字体与数字排版（Typography）

电力交易包含大量的“96点出清价”、“申报电量”、“结算金额”，普通的字体会导致多位数对齐困难，且缺乏科技感。

* **中文字体：** `PingFang SC`, `Microsoft YaHei`, 无衬线体。要求字形方正，在中后台密集表格中不易粘连。
* **数字字体（关键）：** 引入 **`DIN Alternate`** 或 **`Roboto Mono`**。
* *优势：* 这类字体属于**等宽字体（Monospace）**，不论数字是 `1` 还是 `8`，所占宽度完全一致。这样在现货行情高频刷新时，数字不会来回抖动，极具极速量化的科技感。


* **字阶规范：**
* 大屏核心出清价：`36px` - `48px`（粗体，带轻微 `#00F2FE` 外发光）
* 卡片标题/重要指标：`18px` - `20px`（中粗）
* 正文/表格数据：`14px`（常规）
* 次要标签/时间戳：`12px`（淡灰色 `#8F9BBA`）

## 四、 空间布局与网格系统（Layout & Grid）

为了打造“电力控制室”的专业感，整体布局应当紧凑、模块化。

* **全屏控制台（Dashboard）架构：** 采用顶栏（Header）+ 左右对称布局，中间留给核心的 ECharts 现货价格曲线。
* **微缝间距（Micro Gaps）：** 卡片间距定义为 `12px` 或 `16px`。相比传统办公系统的宽松，电力交易系统需要更高的数据密度，让交易员在一个屏幕内总览全局。
* **容器科技感点缀：**
* **切角效果：** 卡片边框不使用大圆角，采用 `2px - 4px` 的小圆角，甚至使用 CSS 裁剪出 `45度切角`，模拟军工级硬件边缘。
* **半透明微光（Glassmorphism）：** 卡片背景采用 `background: rgba(17, 28, 68, 0.75); backdrop-filter: blur(10px);`，营造半透明玻璃质感，透出底部的隐约科技网格。

## 五、 组件视觉特征（Component Details）

基于 Vue 3 + Element Plus，可以通过深度自定义样式（CSS Variables）来实现科技感定制：

### 1. 边框与线条（Border & Lines）

* 拒绝粗重的实线，采用 `1px` 的微光边框，颜色为 `rgba(0, 242, 254, 0.15)`。
* 关键激活态卡片，可增加边框渐变线（Cyan 到 Blue）以及极其微弱的 `box-shadow: 0 0 8px rgba(0, 242, 254, 0.3);`（呼吸灯外发光效果）。

### 2. 表格设计（Datatable）

电力交易最核心的组件。

* **表头：** 采用深蓝色底 `#172554`，文字加粗纯白。
* **斑马纹：** 奇偶行交替，偶数行背景透明，奇数行背景 `rgba(255, 255, 255, 0.02)`。
* **高亮悬浮：** 鼠标悬停行（Hover）背景变为 `rgba(0, 242, 254, 0.08)`，并伴有左侧一条 `2px` 宽的科技蓝垂直指示线。

## 六、 数据可视化（ECharts & AntV 专项规范）

图表是这套辅助决策系统的“灵魂”，必须统一风格：

* **曲线动效：** 现货 96 点价格曲线进场时，设置 `animationDuration: 2000`，配合 `easing: 'cubicOut'`，呈现平滑延展的科技感进场特效。
* **面积渐变（Area Style）：** 负荷曲线、出清价格线下方，配置从科技主色到透明的渐变面积填充（例如：`rgba(0, 242, 254, 0.2)` 渐变至 `rgba(0, 0, 0, 0)`），视觉层次感极强。
* **标记线（MarkLine）：** 市场最高限价、最低限价、以及发电机组的成本线，采用红色或黄色的虚线（Dashed Line）横贯全图，并带有动态流光或文字标签。
* **拓扑图（AntV X6）：** 电网节点、售电公司与大用户之间的电力零售合同流转图，节点采用科技感小方块，连线采用“发光流体动画（Marching Ants Effect）”，实时表现电量或业务流的流向。

## 💡 落地实施建议

这套规范完全可以通过在 **Vue 3** 项目的入口文件（如 `main.ts` 或 `App.vue`）中，定义一套 **CSS 全局变量（Variables）** 完美落地：

```css
:root {
  --theme-bg: #0A1128;
  --theme-card-bg: rgba(11, 28, 68, 0.8);
  --color-primary: #00F2FE;
  --color-success: #00E676;
  --color-danger: #FF3860;
  --font-number: 'Roboto Mono', 'DIN Alternate', monospace;
}

```

在后续开发 Element Plus 表单、ECharts 颜色配置时，直接引用这些变量，即可确保全系统视觉高度统一、极具科技质感。
