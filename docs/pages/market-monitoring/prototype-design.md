# 市场监测模块原型设计

## 1. 设计目标

市场监测模块服务于交易决策前的行情观察。页面应帮助交易员快速判断：价格是否异常、供需是否偏紧、负荷趋势是否变化、是否需要进入申报或策略调整。

设计风格沿用 `docs/pages/pages_design_V1.md`，采用深色控制台、高信息密度和高对比风险提示。

## 2. 模块信息架构

```text
市场监测
├── 市场行情总览
│   ├── 筛选栏
│   ├── 核心 KPI
│   ├── 日前/实时价格 + 负荷趋势
│   ├── 供需概览
│   ├── 风险观察
│   └── 高频入口
├── 价格监测
│   ├── 日前出清价格
│   ├── 实时出清价格
│   ├── 现货价格走势
│   ├── 竞价价格分析
│   ├── 价差分析
│   └── 市场价格排名
├── 供需分析
├── 跨省联络线
├── 气象监测
├── 交易日历
└── 市场参数
```

## 3. 市场行情总览原型

### 3.1 桌面布局

```text
┌──────────────────────────────────────────────────────────────┐
│ 筛选栏：交易日 | 市场类型 | 时段粒度 | 区域 | 自动刷新 | 更新时间 │
├──────────┬──────────┬──────────┬──────────┬──────────┬──────────┤
│ 日前均价 │ 实时均价 │ 最大价差 │ 系统负荷 │ 供需裕度 │ 风险告警 │
├──────────────────────────────────────────────┬───────────────┤
│ 日前/实时价格 + 负荷趋势图                    │ 风险观察       │
│ ECharts 折线、面积渐变、限价/风险 MarkLine     │ 越限/偏紧/异常 │
├──────────────────────────────┬───────────────┬───────────────┤
│ 供需概览                     │ 交易节点       │ 快捷入口       │
│ 供给/需求/备用/净负荷          │ 开市/申报/出清 │ 价格/申报/日历 │
└──────────────────────────────┴───────────────┴───────────────┘
```

### 3.2 核心 KPI

| 指标 | 含义 | 状态规则 |
|---|---|---|
| 日前均价 | 当前交易日 DA 均价 | 较昨日上涨明显标红 |
| 实时均价 | 当前 RT 均价 | 高于日前均价标黄或红 |
| 最大价差 | DA-RT 最大绝对价差 | 超阈值标红 |
| 系统负荷 | 当前或预测负荷 | 高峰时段标黄 |
| 供需裕度 | 可用供给与需求差值 | 低裕度标红 |
| 风险告警 | 当前有效风险事件数 | 有高风险标红 |

### 3.3 趋势图

图表内容：

- 日前价格：青色折线。
- 实时价格：黄色折线。
- 负荷预测：蓝色虚线，可使用右轴。
- 实际负荷：绿色折线，可使用右轴。
- 最高限价/风险阈值：红色虚线 `markLine`。

交互：

- Hover 展示时段、DA 价格、RT 价格、价差、预测负荷、实际负荷。
- 点击异常点后续可联动风险详情抽屉。
- 自动刷新开关默认关闭，后续接入 SSE/WebSocket。

### 3.4 风险观察

风险卡片按优先级排序：

- 高风险：价格越限、供需严重偏紧、联络线满载。
- 中风险：价差扩大、预测负荷偏高、关键节点临近。
- 低风险：普通市场提醒。

每条风险显示：风险标题、来源、时间、简短说明。

## 4. 价格监测原型

### 4.1 页面结构

```text
┌──────────────────────────────────────────────────────────────┐
│ 筛选栏：交易日 | 市场类型 | 区域/主体 | 时段粒度 | 导出          │
├──────────────────────────────────────────────────────────────┤
│ Tab：日前出清 | 实时出清 | 现货走势 | 竞价分析 | 价差分析 | 排名 │
├──────────────────────────────────────────────┬───────────────┤
│ 当前 Tab 主图表                               │ 摘要指标       │
│ 96 点价格曲线 / 价差曲线 / 竞价对比            │ 均价/峰值/谷值 │
├──────────────────────────────────────────────────────────────┤
│ 明细表格：时段、价格、电量、价差、状态、备注                  │
└──────────────────────────────────────────────────────────────┘
```

### 4.2 Tab 内容

| Tab | 展示重点 |
|---|---|
| 日前出清价格 | DA 96 点价格曲线、峰谷值、均价 |
| 实时出清价格 | RT 价格曲线、实时刷新状态、异常点 |
| 现货价格走势 | DA/RT/现货价格对比趋势 |
| 竞价价格分析 | 申报价与出清价对比、偏离程度 |
| 价差分析 | DA-RT 价差、正负价差分布 |
| 市场价格排名 | 区域/主体价格排名、Top/Bottom 列表 |

## 5. 视觉规范

颜色：

- 背景：`#0A1128`
- 面板：`rgba(17, 28, 68, 0.75)`
- 主高亮：`#00F2FE`
- 次级蓝：`#0072FF`
- 风险红：`#FF3860`
- 安全绿：`#00E676`
- 预警黄：`#FFB300`
- 次要文字：`#8F9BBA`

布局：

- 页面间距使用 `12px` 或 `16px`。
- 卡片圆角 `2px - 4px`。
- 表格行高保持紧凑，适合行情盯盘。
- KPI 数字使用等宽数字字体。

## 6. 响应式规则

- 桌面端：KPI 六列，主趋势图占 `2/3`，风险观察占 `1/3`。
- 中屏：KPI 三列换行，趋势图与风险观察上下排列。
- 小屏：全部单列，价格监测 Tab 可横向滚动。
- 图表高度不低于 `300px`，移动端不低于 `260px`。

## 7. 状态设计

必须覆盖：

- 正常：展示 mock 行情和风险数据。
- 加载中：筛选栏下方局部 loading 或骨架屏。
- 空数据：展示“当前筛选条件下暂无行情数据”。
- 异常：展示“行情数据获取失败，请稍后重试”。
- 高风险：红色边线和醒目标识。
- 无权限：隐藏或禁用导出、配置类按钮。

## 8. 与其他模块联动

- 从风险观察可进入 `交易管理 / 现货交易申报`。
- 从价格异常可进入 `价格监测` 对应 Tab。
- 从交易节点可进入 `交易日历`。
- 从供需偏紧可进入后续 `供需分析` 页面。
- 工作台首页中的“价格监测”快捷入口应跳转到 `/market-monitoring/prices`。

## 9. 原型验收标准

- 市场监测模块具备清晰的总览页和价格页结构。
- P0 功能优先，P1/P2 不阻塞 V1 开发。
- 图表、KPI、风险和表格信息层级清晰。
- 风险状态颜色与视觉规范一致。
- 原型可直接转化为 Vue 组件拆分和测试用例。
