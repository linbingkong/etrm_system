# 价格预测页面原型设计

## 1. 页面定位

价格预测页面归属 `市场监测` 模块，路由为 `/market-monitoring/price-forecast`。页面面向交易决策人员，提供按时间范围查看预测价格、实际价格、预测偏差、置信区间和风险时段的能力，为现货申报和策略复核提供前置判断。

## 2. 信息架构

```text
市场监测 / 价格预测
├─ 筛选区
│  ├─ 交易日期范围
│  ├─ 市场类型：日前 / 实时 / 全部
│  ├─ 区域/节点
│  ├─ 时间粒度：24点 / 96点
│  └─ 模型版本
├─ 核心指标
│  ├─ 预测均价
│  ├─ 最高预测价
│  ├─ 高风险时段
│  └─ 平均预测偏差
├─ 预测价格曲线
│  ├─ 预测价格
│  ├─ 实际价格
│  ├─ 置信区间
│  └─ 高价风险阈值
├─ 风险时段提示
└─ 时段明细表
```

## 3. 页面布局

```text
┌────────────────────────────────────────────────────────────┐
│ 标题：价格预测                         24点 / 96点 / 导出  │
├────────────────────────────────────────────────────────────┤
│ 交易日期范围 | 市场类型 | 区域节点 | 时间粒度 | 模型版本 | 更新时间 │
├──────────────┬──────────────┬──────────────┬──────────────┤
│ 预测均价      │ 最高预测价    │ 高风险时段    │ 平均预测偏差  │
├──────────────────────────────────────┬─────────────────────┤
│ 预测价格曲线                          │ 风险时段提示         │
│ 预测价格 / 实际价格 / 置信区间 / 阈值线 │ 高价、低价、偏差风险 │
├──────────────────────────────────────┴─────────────────────┤
│ 时段明细：时段 / 预测价 / 实际价 / 偏差 / 置信区间 / 风险等级 │
└────────────────────────────────────────────────────────────┘
```

## 4. 关键交互

- 支持 `24点` 与 `96点` 切换，切换后 KPI、曲线和明细表同步刷新。
- 支持交易日期范围、市场类型、区域/节点、模型版本筛选，首版使用前端 mock 数据。
- 图表 Hover 展示时段、预测价、实际价、偏差、置信区间和风险等级。
- 风险提示按风险等级排序，高价风险使用红色，波动提示使用黄色。
- 导出按钮首版置灰，预留权限控制与接口接入。

## 5. 数据字段

```ts
interface PriceForecastPoint {
  time: string;
  forecastPrice: number;
  actualPrice?: number;
  deviation?: number;
  confidenceLow: number;
  confidenceHigh: number;
  riskLevel: 'low' | 'medium' | 'high';
  suggestion: string;
}
```

## 6. 验收标准

- 菜单新增 `价格预测`，位于 `价格监测` 之后。
- 页面路由为 `/market-monitoring/price-forecast`。
- 页面包含筛选区、4 个核心指标、预测价格曲线、风险时段提示和明细表。
- 支持 24/96 点展示切换。
- 页面视觉遵循 `docs/pages/pages_design_V1.md` 的深色控制台风格。
