# 山东电力交易辅助决策系统 - 菜单规划

## 1. 规划原则

本菜单规划基于《山东电力交易辅助决策系统-功能清单.md》。系统采用“业务域一级菜单 + 高频功能二级菜单 + 明细页面隐藏路由”的结构。

- 一级菜单对应功能清单中的 13 个业务模块。
- P0/P1 功能优先进入主菜单或页面 Tab。
- P2 功能默认作为配置页、隐藏路由、弹窗、抽屉或管理员入口。
- 详情、编辑、审核弹窗、数据抽屉类功能不占用左侧菜单。
- 路由使用英文 kebab-case，权限编码使用 `module:action` 格式。

## 2. 路由与权限约定

| 项目 | 约定 |
|---|---|
| 路由前缀 | `/dashboard`、`/market-monitoring`、`/trading` 等业务域 |
| 菜单编码 | `market-monitoring:prices`、`settlement:review` |
| 按钮权限 | `trading:spot-bid:submit`、`settlement:review:approve` |
| 菜单类型 | `directory`、`menu`、`button` |
| 默认可见性 | P0 默认显示，P1 按角色授权，P2 默认隐藏或仅管理员可见 |

建议菜单数据字段：

| 字段 | 说明 |
|---|---|
| `id` | 菜单唯一 ID |
| `parentId` | 父菜单 ID，一级菜单为空 |
| `code` | 权限编码 |
| `title` | 菜单名称 |
| `path` | 前端路由 |
| `component` | 前端组件路径或布局标识 |
| `icon` | 菜单图标 |
| `type` | `directory`、`menu`、`button` |
| `priority` | `P0`、`P1`、`P2` |
| `sort` | 同级排序 |
| `visible` | 是否显示在侧边栏 |
| `permission` | 权限标识，默认与 `code` 一致 |

## 7. 校验清单

- 13 个一级菜单均来自功能清单。
- P0 功能均有菜单入口或明确合并到聚合页。
- 弹窗、抽屉、详情、编辑类功能不直接进入侧边栏。
- 路由命名与 `frontend/src/views/` 当前业务目录一致。
- 菜单权限编码可同时支持页面级权限和按钮级权限。
- P2 功能保留在路由与权限设计中，但默认不占用主导航空间。
