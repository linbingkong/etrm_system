# 山东电力交易辅助决策系统 — 产品需求文档 (PRD)

## 1. 产品概述

### 1.1 产品定位

山东电力交易辅助决策系统是面向山东省电力市场参与主体（发电企业、售电公司、大用户等）的一站式电力交易辅助决策平台。系统以电力市场数据为核心，提供从市场监测、交易决策、合同管理、结算对账到考核分析的全链路支撑，帮助用户在中长期市场、现货市场、辅助服务市场等多品种市场环境中做出更优决策。

### 1.2 产品目标

1. **提升交易决策效率** — 通过数据可视化、预测模型和策略推荐，辅助交易员快速决策
2. **降低交易风险** — 实时监控市场行情、价格波动和偏差考核，及时预警
3. **全流程闭环管理** — 覆盖"市场分析→交易申报→合同管理→结算对账→考核分析"全链路
4. **多市场协同** — 打通中长期与现货市场，支持电力中长期合约、现货日前/实时市场协同

### 1.3 目标用户

| 用户角色 | 主要职责 |
|---------|---------|
| 交易决策人员 | 制定交易策略、执行报价申报、监控市场行情 |
| 结算管理人员 | 结算单核对、费用审核、偏差分析 |
| 合同管理人员 | 合同录入、续签、归档管理 |
| 数据分析人员 | 市场分析、预测建模、报表生成 |
| 系统管理员 | 用户权限配置、系统参数维护、字典管理 |

## 2. 系统总体架构

本系统采用**前后端分离架构**。

- **前端**以 **Vue 3 (Composition API)** 配合 **TypeScript** 为核心开发语言，基于 **Vite** 构建高效的开发与打包环境。利用 **Element Plus** 快速搭建密集型表单与中后台管理界面，状态管理采用 **Pinia** 维护多市场上下文及仓位状态。针对系统的命脉——数据可视化与大屏监控，深度集成 **Apache ECharts**（用于现货价格及偏差曲线）与 **AntV X6**（用于交易闭环流程图），并通过原生 **WebSocket / SSE** 实现行情与预警数据的毫秒级实时推流。
- **后端**选择基于 **Python** 的高性能异步框架 **FastAPI**，利用其天然支持的 `async/await` 异步生态应对多用户、高并发的报价及出清数据处理。借助 **Pydantic v2** 进行强类型的数据校验与序列化，并通过其生成的 OpenAPI 规范，利用工具链将后端数据模型直接同步为前端 TS 类型，确保前后端数据契合度。
- **数据库层**采用“关系型 + 时序型 + 缓存”的组合拳方案。核心业务数据（如合同、结算对账、系统权限）由 **PostgreSQL** 关系型数据库承载，确保 ACID 事务安全；对于海量的电力现货价格、负荷曲线等高频时序数据，采用基于 PostgreSQL 的 **TimescaleDB** 扩展进行高效存储与流式聚合分析；同时，引入 **Redis** 作为高速缓存与 WebSocket 的消息发布/订阅（Pub/Sub）中心，保障实时行情的极速响应。

## 4. 非功能性需求

### 4.1 性能要求

| 指标 | 要求 |
|------|------|
| 页面加载时间 | 首屏 < 3s，页面切换 < 1s |
| 数据查询响应 | 常规查询 < 2s，复杂报表 < 5s |
| 并发用户数 | 支持 200+ 并发用户 |
| 数据刷新频率 | 市场实时数据 1-5 分钟，结算数据 T+1 |

### 4.2 安全要求

- 基于 JWT 的 Token 认证
- 按钮级权限控制（前端指令权限）
- 数据隔离（企业间数据不可见）
- HTTPS 传输加密
- 操作日志审计

### 4.3 可用性要求

- 系统 7×24 小时运行
- 年可用性 ≥ 99.5%
- 数据每日自动备份
- 关键操作支持回滚

### 4.4 兼容性要求

- 支持 Chrome / Firefox / Edge 最新版本
- 支持暗色模式 (Dark Mode)
- 响应式布局，支持不同分辨率

## 6. 技术架构

| **层次**            | **核心选型**                     | **关键职责与优势**                                           |
| ------------------- | -------------------------------- | ------------------------------------------------------------ |
| **前端 (Frontend)** | Vue 3 + TS + Vite + Element Plus | 高效的组件化开发，强类型规避“量/价/费”计算逻辑错误，响应式系统轻松应对多仓位状态变更。 |
| **数据可视化**      | Apache ECharts + AntV X6         | 支撑 96点/288点 现货价格曲线、K线图的大数据量渲染，以及电网节点拓扑与交易流转可视化。 |
| **后端 (Backend)**  | Python + FastAPI + Uvicorn       | 纯异步高并发处理能力，完美契合现货日前/实时市场的高频接口请求与实时出清计算。 |
| **核心关系数据库**  | PostgreSQL                       | 存储合同、结算、考核规则等核心资产，具备强大的 JSONB 复杂对象处理能力。 |
| **时序数据库**      | TimescaleDB (基于 PG)            | 专门应对现货高频 Tick 数据、日前/实时出清价格曲线的秒级写入与历史大范围时序聚合。 |
| **缓存/实时流**     | Redis                            | 缓存静态规则、盘前行情数据，并作为多交易员在线时的消息分发底座。 |
